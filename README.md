# CPE 301 Final Project
Tamper Detection System

By: Arwen Antes

A project utilizing an Arduino Mega 2560 controller and a GY-521 accelerometer module and photoresistor to make an alarm system that will alert based on changes in light or physical disturbances. 

A user can arm the system and be given time to move away from the detection system, where it will take initial recordings of the light and position of the accelerometer. If any tampering or changes in light are detected, an alarm will go off through the buzzer and events will be logged. The system can only be reset and rearmed by the user by inputting the correct pin.
